# Minimal Magazine WordPress Theme

A clean, minimal magazine-style WordPress theme with a white design and tag filtering functionality.

## Features

- **Clean White Design**: Minimalist aesthetic with plenty of whitespace
- **Tag Filtering**: Filter posts by tags/categories at the top of the page
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Post Thumbnails**: Optional featured images for each post
- **Modern Typography**: Uses Inter font for clean, readable text
- **SEO Optimized**: Clean code structure and proper WordPress standards
- **Customizable**: Easy to customize through WordPress Customizer

## Installation

1. **Download the theme**: Download all theme files to your computer
2. **Upload to WordPress**: 
   - Go to your WordPress admin panel
   - Navigate to Appearance > Themes
   - Click "Add New" then "Upload Theme"
   - Choose the theme zip file and click "Install Now"
3. **Activate the theme**: Click "Activate" after installation
4. **Customize**: Go to Appearance > Customize to modify theme options

## Manual Installation

If you prefer manual installation:

1. Create a folder named `minimal-magazine-theme` in your WordPress themes directory (`wp-content/themes/`)
2. Upload all theme files to this folder
3. Go to Appearance > Themes in your WordPress admin
4. Activate the "Minimal Magazine" theme

## Required Files

The theme includes these essential files:

- `style.css` - Main stylesheet with theme information
- `index.php` - Main template file for the blog feed
- `header.php` - Header template
- `footer.php` - Footer template
- `functions.php` - Theme functions and setup
- `single.php` - Individual post template
- `archive.php` - Archive pages template
- `404.php` - Error page template

## Customization

### Theme Customizer

1. Go to Appearance > Customize
2. You'll find a "Theme Options" section where you can:
   - Add custom CSS
   - Modify theme settings

### Custom CSS

You can add custom CSS through:
1. WordPress Customizer > Theme Options > Custom CSS
2. Or directly edit the `style.css` file

### Colors and Typography

The theme uses a clean color palette:
- Primary text: #333
- Secondary text: #666
- Muted text: #888
- Borders: #f0f0f0
- Background: #fff

Typography uses the Inter font family for a modern, clean look.

## Post Features

### Featured Images

To add featured images to your posts:
1. Edit a post
2. In the right sidebar, find "Featured Image"
3. Click "Set Featured Image"
4. Upload or select an image
5. The image will appear at the top of the post

### Tags and Categories

The theme automatically displays:
- Post categories in the meta section
- Post tags at the bottom of each post
- Tag filtering buttons at the top of the page

### Excerpts

The theme uses WordPress excerpts for post previews. To create custom excerpts:
1. Edit a post
2. In the right sidebar, find "Excerpt"
3. Add your custom excerpt text
4. If no excerpt is provided, WordPress will automatically generate one
