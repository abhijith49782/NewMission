# Minimal Magazine WordPress Theme

A clean, minimal magazine-style WordPress theme with a white design and tag filtering functionality.

## Features

- **Clean White Design**: Minimalist aesthetic with plenty of whitespace
- **Tag Filtering**: Filter posts by tags using the filter buttons at the top
- **Responsive Layout**: Works well on desktop, tablet, and mobile devices
- **Featured Images**: Support for post thumbnails and featured images
- **Typography**: Clean typography using Georgia serif font
- **Navigation**: Simple previous/next navigation
- **SEO Friendly**: Proper HTML structure and meta tags

## Installation

1. Download the theme files
2. Upload the `minimal-magazine-theme` folder to your WordPress themes directory (`/wp-content/themes/`)
3. Go to Appearance > Themes in your WordPress admin
4. Activate the "Minimal Magazine" theme

## Usage

### Setting Up Your Blog

1. **Site Title & Description**: Go to Settings > General to set your site title and description
2. **Posts**: Create posts and add tags to them for the filtering functionality
3. **Featured Images**: Set featured images for your posts to display them in the feed
4. **Tags**: Add tags to your posts to enable the filtering feature

### Customization

The theme uses a clean, minimal design that's easy to customize:

- **Colors**: Edit the CSS variables in `style.css` to change colors
- **Typography**: Modify font families and sizes in `style.css`
- **Layout**: Adjust the container width and spacing in `style.css`
